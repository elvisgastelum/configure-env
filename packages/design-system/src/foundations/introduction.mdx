# Design system

The visual language of the configure-env portal, copied from elvisgastelum.com and named and documented in one place. Every token on these pages is read from the typed catalog in `src/tokens.ts`, and every sample renders with the package's own CSS, so what you see here is what ships.

## Use it in code

Tokens are CSS custom properties and Tailwind utilities; recipes are class strings you pass to `className`.

  minWidth="36rem"

<Callout title="Tailwind sees source text">
  Recipes are plain string literals so Tailwind's scanner finds every class.
  Never assemble a class name from pieces at runtime; combine whole recipes with
  `cn()`.
</Callout>

## Theme and language

Use the toolbar above the canvas:

- **Theme** (contrast icon): System, Light or Dark. It sets the class on the preview's `<html>`, exactly as the site's theme toggle does, and repaints these docs pages too.
- **Language** (globe icon): Español (MX) or English (US), for components with translated text.

The theme variables live on the root element only, so a page cannot show both themes at once with live colors. The Colors page shows both themes from the literal values instead; every other sample follows the toolbar.
