# Typography

One self-hosted variable font, Geist, for headings and running text. Headings are tight and balanced; leads are muted and pretty-wrapped.

## Text recipes

Use a `TYPE` recipe instead of composing sizes and weights by hand:

```tsx
import { TYPE } from '../recipes';

<h2 className={TYPE.sectionTitle}>Services</h2>;
```
